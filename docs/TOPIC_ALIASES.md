# 主题叫法与导航规则

「主题叫法」让用户明确登记同一主题的不同名称，例如“学习方法”“学习策略”。只拓展检索导航，不修改原始主题，不自动分类记录，不将同义规则作为个人事实。页面新增、修改、归档和恢复均为本地操作，打开和保存不调用模型。

## 接口与约束

`TopicAliases(repository)` 提供 `page(offset, limit, includeArchived)`、`get(id)`、`save(canonical, aliases, id?, expectedRevision?)`、`archive(id, expectedRevision, archived)` 与 `expand(Set<String>)`。目录每页最多 100 项；最多同时启用 100 组、保留 10,000 组。每组 1–20 个不同于主叫法的别名，每词 1–80 个 Unicode 码点；空白、控制字符及换行词拒绝。输入经 NFKC、首尾去空白及不依赖设备语言的大小写统一，再检查冲突。

一个规范化后的词只能属于一组当前规则。跨组冲突时保存或恢复失败；检查与写入在同一数据库锁和事务中，旧版本不能覆盖新修改。归档保留历史但停止拓展；恢复须重新检查当前冲突和容量。恢复合并可能带来彼此冲突的规则，`expand` 将明确拒绝，不默默任选一组。打开规则目录仍可定位和修改冲突。超过容量报错，不能把前 100 项冒充完整规则集合。

`expand` 保留原调用方的词，并加入规范化及同组词；它进行完整词匹配，不猜测词义或做无限递归。最多一次接受 100 个输入词。调用方仍须保留后续检索预算和原始查询范围，拓展不扩大可读日期，也不成为原始依据。

已有理解目录会用这些词匹配现有主题，并从问题中选择实际提到的叫法组；完整字典不进入模型上下文。本地查找同时支持正文叫法和主题筛选的同义匹配，逐页遍历原记录、知识与经验历史，配置记录本身不会作为生活搜索结果。经验关联建议也可根据用户指定的同义主题推荐，实际关联仍需确认。归档规则后，重新查找立即停止该拓展，已经保存的原标签和知识不改写。

## 主存、备份与证据边界

规则保存在普通版本化记录中，绑定固定问题内容身份的模板；名称或单个 intent 一样不足以视为配置。目录 SQL 只读取匹配模板的记录身份与两个限定长度的答案，不扫描全部生活正文。模板后来出现新版本不改变旧记录所绑定的问题含义。

内部叫法模板不出现在普通复盘模板列表。已有缺失或超长答案的配置仍保留身份、原文和历史，在叫法管理页明确显示未用于查找，可打开原文、修复或归档；不让这些无效行阻断有效规则及普通提问。修复使用当前修订校验，只更新两项叫法答案，保留原正文、日期、标签、附件与旧版本。跨组同名冲突仍须明确处理，不能悄悄选择其中一组。

复用既有修订、归档、删除及完整备份机制，不新增主库 schema。旧备份不能恢复本地已永久删除的规则；目标库已有修订按原记录合并约定处理。`RecordFilter.includeConfiguration` 为兼容原接口默认 `true`；首页日记流明确设为 `false`，在 SQL 计数及分页前统一排除配置，未知时间数同样不计入。规则由专用目录管理，不属于工作、学习等行为指标。

默认分析范围（`recordIds == null`）在统一 SQL 范围入口排除精确模板身份的配置记录，因此资料枚举、未知日期计数、字段、原文及指标使用相同边界。用户明确指定 ID 时仍可查看配置本身，其模板提示和正文明确说明不是生活事件或事实。后台新记录整理也跳过配置，不因改一个叫法而产生提取费用。

普通生活范围的有效性检查，只忽略能证明所有保留历史修订都为导航配置的记录变化。删除前仍能证明该身份从未是生活记录时，先清理明确指定该身份的任务及其后代，并保存删除身份，再清除该纯配置的范围变更登记；删除一个叫法不会使所有日期的生活分析失效。显式指定但尚未取证的任务也清理，旧备份不能复活它们。原本是生活记录、后来被改成配置时不适用此例外，旧分析仍失效。导航规则并不替换任何已固定任务的证据或派生上下文。

知识阅读包将精确身份的配置从生活记录、主题、未知时间、ID 及证据目录排除；另从 `navigation/topic-aliases/index.md` 分页读取相同导出范围内的当前规则。每项只保留规范叫法、其他叫法、记录／修订身份、保存时间和归档状态，不复制原配置正文、附件或历史。机器索引仅含定位元数据；叫法答案保留在单项 Markdown。manifest 单列纳入、省略及原因，缺失或无效答案明确省略；证据包省略全部配置。未知时间、主题和归档条件不因配置用途而放宽。完整备份继续保留全部原始配置与修订。

## 验证

`TopicAliasesTest` 检查规范化、冲突事务、旧版本、归档恢复、目录分页、模板内容身份、默认分析范围隔离、显式配置取证、生活记录转换的失效、后台跳过、备份与删除传播；包含删除纯配置时保留无关隐式任务、清理显式已读／未读任务以及旧备份不复活的行为用例。`TopicAliasRetrievalTest` 检查实际原文／知识／经验命中、跨页主题筛选、问题与导航词路由、经验建议、归档停止匹配以及短英文词边界。`TopicAliasesActivityTest` 检查表单重建、明确保存、归档确认及零模型调用。实际运行结果由开发验证文档统一记录。
