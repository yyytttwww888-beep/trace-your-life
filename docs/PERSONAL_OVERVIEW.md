# 个人概览与当前方向

手机「此刻的我」把用户写下的当前方向，与已采用画像、经验线索、选定行动和最近保存的知识接在一起。该页面不调用模型，也不生成全面人格判断；每节先显示少量内容，再跳转到完整目录或原文。实现位于 `overview/PersonalOverview.kt` 与 `ui/OverviewActivity.kt`。

## 当前方向

用户可填写当前阶段与约束、目标、关注点、观察信号、声明日期和可选的回看日期；至少填写一项正文。目标可以是维持、休息或改变，不强制量化或转成行动。声明日期不能晚于今天，未来安排写在目标中；回看日期到期只提示适合再看，不表示目标失败。

这些原话复用普通记录、模板绑定、来源修订及删除流程，未增加另一套可写主存。模块通过固定的问题 ID、意图和完整模板内容识别版本，不靠主题或标题猜测含义。模板 ID 是正常资料身份；如果用户修改模板，新版本不重新解释早先绑定旧版的记录。专用编辑保留原记录正文、附件、主题及原模板版本，只更新对应回答与声明日期。

创建调用携带稳定的 `creationId`，重试不会重复记录；修改使用 `recordId` 和 `expectedRevision`，拒绝覆盖其他页面的新修订。旧用户文字随记录历史保留。修改、归档、删除以及来源范围变化继承原有失效与依赖传播。创建目标不是实际达成的证据，也不是已采用画像。

多份当前方向按最后一次正文、回答、日期等内容实际变更的时刻及稳定 ID 选择最近一份；仅归档或取消归档不会改变声明先后，归档旧方向不会遮住较新的方向。归档真正最近的一份后，不自动退回较早目标作为当前方向；可从原始记录查看历史或明确再写新的方向。永久删除清除该记录及其旧修订；其他独立记录继续保留。已删除身份不复用。跨日重新打开会重新判断回看日期。

## 已有理解与行动

`PersonalOverview.open(limit = 3)` 返回固定读取时点的本地阅读视图，校验来源与分析代数，分别保留各节总数和有限条目：

- 当前有效且明确采用的画像，显示维度、引用陈述和适用范围，可进入共享知识与原始证据。
- 当前采用理解仍有效的经验线索，可进入补充、例外和替代过程。
- 开放行动及计划回看日期；仅是用户选择，不推断已执行。
- 最近 30 天保存且仍有效的知识；保存时间与经历发生时间分别说明。
- 需要更新的知识数量；不作为当前结论展示失效文字。

输入区不会把这些派生文字自动填进用户目标。页面重建保留尚未保存的表单及修订身份；来源被其他页面修改时拒绝旧表单提交。离开后返回会刷新阅读视图；若返回时旧读取尚未完成，保留待刷新请求，交付旧结果后再读取当前资料，不因忙碌状态漏掉变化。编辑中的表单不被返回刷新覆盖。

## 备份与跨 AI 阅读

当前方向作为普通记录进入完整加密备份，恢复保留问题版本、回答及修订，目标库已知删除继续优先。无需新增数据库或逻辑备份格式。应用凭据仍不进入任何导出。

知识阅读包新增 `overview.md`，README、分层索引和 manifest 均提供入口。概览只呈现同包已经纳入的用户当前方向与有效知识、画像、经验、行动；不扩大时间或主题范围。先在完整快照中定位真正最新方向，再判断是否位于导出范围，不能在新方向省略时把旧方向冒充当前。证据包不生成概览。

每个方向字段最多显示 240 个 Unicode 码点，明确标为节选并链接完整原文；画像与知识只显示维度、类型、范围、修订和导航，不复制机器陈述或截取摘要，保证 Markdown 知识正文只有一个权威位置。每节最多显示 3 项，完整目录继续分页。用户自述、已采用画像、关联与计划分别标明性质。概览是固定历史阅读视图，不会随应用内后续修改而更新；所有相对链接和文件清单沿用导出验证。它不提供完整恢复历史，完整恢复仍使用加密备份。

明确选择 `includePersonalHistory` 时，概览另提供 `personal-history/index.md`，可以阅读画像组织修订、用户核对反馈、历史对照理由、经验形成说明和独立行动回看。每项保留保存时间、原关联身份及缺失／删除状态；历史状态不作为当前画像，独立原话也不替缺失的模型判断背书。按日期、类型和画像 ID 分页定位，范围与完整性规则见[数据转移接口](DATA_TRANSFER.md#自己的说明与历史变化)。

自动测试覆盖记录修订、重试、识别边界、旧模板绑定、归档／删除、范围不泄漏、Unicode 节选、完整恢复、页面重建与并发编辑，以及在旧读取待交付期间离开／返回的刷新。实际运行结果统一见[开发与验证](DEVELOPMENT.md)，测试代码存在不代表已经执行。
