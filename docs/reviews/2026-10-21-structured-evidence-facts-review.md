# 结构化来源事实与关系核验复评

## 实现

本轮在程序执行的取证范围内，从原文建立可定位的有限事实关系，再传入生成和核对。`EvidenceFacts` 保存来源凭据、码点区间、原文摘句、规范值与关系类型；目标不得反过来补来源事实。核对在有效模型意见之后执行程序检查，保存模型原意见及命中规则，程序只降低支持，不升级模型拒绝。

识别范围包括数量的时长／等待角色、明确步骤和第一步、明确执行状态、可用时长与充分性、局部条件与比较、条件差异与用户归因。规则对明确日期、同活动、原文复述、否定、假设和新建议分别处理；未识别的同义改述、跨事件归属及隐含关系仍依赖模型核对，不能据此承诺普遍语义正确。

生成、普通核对、行动综合、画像候选和最终原文核对共用执行器。归并携带叶事实的派生约束，正式保存仍需重读原文。没有额外模型调用，没有提高输入预算或读取范围。来源事实为空时仅保留台账；供应商发送包去掉重复来源元数据，全部实际事实及原文保留。

分析载荷 v18、知识载荷 v8 保留自包含核验凭据；旧格式可读但不补造证明。备份恢复重新对照原始修订重建关系，删除遵循原有证据依赖。阅读包提供结构化凭据。发送前同时预留输出字节及 JSON 节点，避免已经付费后无法保存新增证明。

## 验收记录

程序回归与真实模型验证分别记录。原有六例、十一守卫、十二对照、六混合句及纵向画像输入不改；报告分开保存 rawModelVerdict、适配器归一的 modelVerdict、programFactFindings 和 finalVerdict，格式失败不计作语义成功。

本轮不启动模拟器；实体手机行为与实际个人资料效果不以离线测试或合成模型样本代替。
