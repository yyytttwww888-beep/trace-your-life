# 知识导航与回看流程实施计划

依据：[本轮设计](../superpowers/specs/2026-10-20-connected-knowledge-workflows-design.md)。

1. 根 Agent：主题概况、本地查找、主题与经验候选、待更新入口，负责统一入口、文档和最终交付。
2. 历史对照 Agent：固定版本的分页语义扫描、严格模型输出、人工采纳建议、v13 载荷兼容与专用页面。
3. 行动 Agent：行动周期生成／归并／核对保存页面，行动与回顾入口、原文与行动依据、恢复状态。
4. 画像与图表 Agent：跨周期长期描述、维护比较／扫描／核对／应用页面，以及记录趋势图和选点下钻。
5. 模块分别完成后统一编译，处理交叉接口，执行行为测试和完整回归；所有 Gradle 调用统一串行。
6. 使用仓库外合成资料验收新增页面和有限真实 DeepSeek 请求，记录失败与修复结果；同签名 APK 发布预览版，提交代码和文档。

共享文件由根 Agent 维护：Manifest、TraceLifeApplication、MainActivity、ReflectionActivity、知识阅读页面、入口文档；受控分析载荷及模型适配器由历史对照 Agent 维护。其他修改先沟通，避免相互覆盖。验收结果在完成后记录，不能将设计勾选视为验证通过。

## 完成记录

七项实现及统一验证已完成，原生控件和既有领域后端复用，无新增依赖。独立评审发现的搜索、分类、分页和行动覆盖问题已修复；离线、真实模型、模拟器的验证范围分别见[开发验证](../DEVELOPMENT.md#知识导航与回看流程验证)。后续真实健康接入与实体手机验收按原路线继续。
