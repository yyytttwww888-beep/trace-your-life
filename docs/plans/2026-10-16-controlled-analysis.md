# M3 第一阶段：受控取证与可恢复的分析提案

用户已确认优先实现功能、前端统一后置。本阶段承接[检索协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)，不改变长期画像和正式发布的验收标准。

## 交付范围

建立固定绝对日期、时区、来源版本和预算的分析任务；通过入口、领域提示、范围计数、分页目录和字段片段定位记录。全周期枚举不按主题过滤，未知日期和跨范围区间单列。附件只登记未处理缺口。

模型调用经过同一执行入口，完整输入计量后才能发送，逐次保存证据定位、请求摘要、预算消耗与结果状态。引用只能来自本次调用提供的原文片段。模型输出只保存为待核对提案，不自动发布为观察、洞察或画像。结构校验不代表语义正确。

任务与调用台账保存在 SQLite，带版本条件更新；重试使用稳定批次标识。来源变化保守地使整个旧任务失效，删除优先清理任务派生文字。任务写入采用独立代数，避免使自己的来源快照失效。完整备份保存任务；恢复后的旧任务保留历史身份，不自动继续执行。

## 实施顺序

1. 增加数据库 v3 迁移、受控元数据查询和 Unicode 码点片段读取、任务保存与并发检查。
2. 实现预算、路由、每次调用的证据登记、提案引用校验、恢复与幂等重试。
3. 扩展版本化备份格式，兼容既有 v1 备份；阅读包声明尚未包含分析提案。
4. 验证分页与误分类、长记录尾部、附件缺口、超预算拒绝、跨调用伪造引用、崩溃与失败重试、来源改动与删除、恢复和过期。
5. 更新实现状态与接口文档，运行单元测试、lint 和 APK 构建，提交独立分支供审阅。

## 本阶段不声称完成的能力

真实模型供应商及其分词器、在线调用、语义支持核对、确定性健康指标、自动观察/知识提取、正式报告发布、范围级精确增量更新与前端均仍需后续实现。测试使用明确的合成记录和可控模型替身；不能据此宣称模型分析质量或真机验证通过。

## 本阶段实际验证

2026-10-16 完成上述后端实现；新增 39 项行为测试，全仓 131 项通过。Android lint 无错误，保留 2 项既有依赖升级提示；调试 APK 构建成功。并发删除测试验证在模型阻塞期间可以删除任务、迟到提案不能重新写回；容量测试验证发送前为响应保留空间。所有资料与模型均为合成测试，真实模型和实体手机未验证。
