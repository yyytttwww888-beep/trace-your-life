# M4 第四阶段：跨任务画像维护与反例检索

用户已明确要求实现上一轮提出的四项功能：关联重复判断、持续尊重纠正、主动查找反例和提出可追溯更新建议。沿用[画像设计](../superpowers/specs/2026-10-16-long-term-personal-profile-design.md)及[受控检索协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)，前端、餐食照片和定时后台运行后置。

## 方案选择

以新候选的任务与陈述身份为入口，复用现有分批生成、分析台账与知识发布；新增纯身份维护计划、逐项陈述比较和原文扫描。分析过程保存结构化关系及证据，实际更新由用户明确选择。保留已有画像 ID，收窄或替换时追加修订并回到候选，独立补充文字不变。

没有采用独立语义向量库与永久“同义族”表：语义检索前几项不能覆盖全部历史纠正，独立机器正文也会增加删除与恢复风险。仅靠提示词让模型自行记住反馈则无法检查范围和写回条件。维护目录、逐项台账与用户操作历史已经能够承担本阶段关联职责，不再复制第二份权威陈述。

本阶段维护近期状态和情境模式的新候选，历史长期条目可参与关联，但不会自动推断新的长期倾向。相似关系是模型意见，不承诺零漏判或天然识别所有同义表达。

## 历史判断与反馈目录

- 维护计划固定目标陈述、维度、层次、建立时间，以及完整适用目录的身份、版本和内容摘要。计划不复制画像或用户纠正正文。
- 同维度画像包含当前、候选、不采用、被替代及来源失效的历史条目；同时纳入尚未物化的纠正、否定、撤回反馈。不能只检查已有当前画像。
- 元数据负责路由，受控比较每次按叶子读取一个参照。旧描述和用户反馈明确属于控制背景，不作为新原始事件或证据。
- 目录、反馈或参照内容变化后，旧检查不能继续作为当前维护凭据。每个候选独立计算比较和扫描进度，不能借用其他候选的处理覆盖。
- 原判断已永久清理、必要上下文不可读取时明确标为缺口，不能自动判为不相关。永久删除过往正文后，不能保证从纯身份恢复其语义；系统不为同义匹配保留被删除正文。

## 关系与反例检查

新增独立受控关系比较和原文扫描调用；复用完整输入计量、来源快照、幂等、预算及错误台账。关系区分同一判断、补充、冲突、不相关和不确定，并提出保留、收窄、替换或继续复核建议。

关系比较处理完整适用目录；主题、词面相似度或前几条命中不能代替完整处理。用户否定、纠正和撤回作为需要显式解决的约束，不能因来源过期而忘记。画像“不采用”只控制采用，不改写共享判断真伪。

原文扫描沿本任务既定时间／ID 范围分页，再按字段分片查找支持、反例、情境和缺失上下文。范围内未分类资料、长记录末尾、未知时间和附件缺口分别报告；扫描覆盖不等于真实生活记录完整。扩大范围须建立新任务。

最终核对重读所有非无关原文和生成候选时的完整输入，并提供相关历史约束。相关原文或约束超过预算时停止，不删掉反例来凑输入；扫描分类和独立核对均不等于真值认证。

## 建议与实际更新

普通生成、比较及扫描不自动确认、发布或采用。维护结果提供关系、建议、约束和覆盖，用户可以保留原条目、明确关联同一判断，或选择已核对的新候选收窄／替换原描述。

收窄或替换在仓储事务内发布共享洞察并更新原画像 ID，保存历史、原独立文字和本次用户操作信息；采用状态回到候选，仍需另行采用。已有否定／限定约束不能仅凭模型建议消失，明确覆盖须记录用户理由。保留原条目不把失效旧知识重新标为有效。

现有候选物化入口接入维护门槛：存在需要比较的历史时，不能绕过维护检查直接创建重复画像。已有同身份的结果仍保持幂等，自己的保存与采用不会让刚发布知识立即失效。手工管理接口仍代表明确用户操作，不开放给模型。

## 保存、失效与删除

分析载荷升级至 v9，保存纯身份计划及比较／扫描／核对凭据，严格读取旧 v1–v8。知识保存自包含维护核对依据，画像修订保存独立用户操作说明；具体内部载荷版本在接口文档记录。数据库和完整备份外层版本无需改变。

执行和应用检查来源、任务版本、完整目录、参照版本、反馈及时间。正式知识的持续有效性检查原始依据、共享反馈和删除关系；自身画像改绑／采用不是共享判断失效事件。保守清理跨任务依赖的机器派生结果，保留独立用户文字；恢复旧备份同样执行当前删除和本地反馈优先。

## 验收与验证

行为测试覆盖：同义／补充／冲突关联；未物化的用户否定；缺失历史上下文；完整目录和逐片扫描；反例在长记录末尾；多候选覆盖隔离；预算耗尽、失败续跑和取消；来源／反馈在途变更；幂等保留与原子替换；独立文字及覆盖理由历史；删除级联、旧格式兼容与恢复优先。

运行相关行为测试、全量离线测试、Android lint 和 APK 构建，并核对 GitHub CI。新增默认关闭的 DeepSeek 合成资料验证，仅使用仓库外既有密钥，以有明确请求上限的案例验证关系判断、反例扫描和最终核对；模型质量与实体手机验收分别报告。
