# 知识保留、主题阅读与手机导出实施计划

用户已要求按旅程评审重新优化。行为以[持续积累设计](../superpowers/specs/2026-10-20-visible-reflection-design.md#评审后的持续积累优化)为准，原始问题与未完成的更长旅程见[评审](../reviews/2026-10-20-user-knowledge-journey-review.md)。本计划不替代总体路线图。

## 并行工作与集成边界

1. **来源和删除维护。** 在 SQLite 中记录来源变化的旧／新范围；增加范围当前性判断，贯通受控读取、模型写回、反馈、核对、知识发布、画像及导出。用实际取证和依赖闭包替代全库清理，保留用户独立文字。迁移和恢复设置保守的历史边界，备份不携带可直接信任的“有效”声明。
2. **Android 文件交付。** 先用应用身份验证默认存储行为，再实现私有目标所有权、完整性登记及原子发布。备份、阅读包、看板和周期导出共用交付入口；系统选址后复制并读回验证，保留可重试的本机完整副本。
3. **知识阅读旅程。** 保存身份与依据状态分开；经验阅读分类匹配保存入口；提供由现有标签组织的主题及原始经历。从正式有效知识发起用户行动，知识与行动／回看双向定位。页面变更仍使用原生单色控件。
4. **集成验证与交付。** 先跑各模块必要行为测试，再运行完整离线测试、lint、APK 构建。覆盖安装专用模拟器，保留旧合成资料，实际测试升级、分析保存、无关变更、主题阅读、行动和系统另存。更新权威接口及验证记录，输出可安装 APK。

## 失败场景

- 未引用但落入分析范围的新资料、未知日期、改日期、归档与精确 ID 过滤，均须按完整候选范围判断；不能只比对已引用记录。
- 模型调用期间删除输入资料，旧返回不能重新写入；永久删除覆盖统计来源、归并证明及画像维护所保留的机器文字。
- 删除无关资料或未使用模板不能丢失其他知识；恢复旧备份不能重新带回已删除的内容，也不能重新认证已失效的知识。
- 普通文件目标的并发写入不得覆盖；私有发布失败不得被列为完整文件；系统提供方截断、关闭失败、重新读取不一致均不得报告成功。
- 返回、旋转和进程重启不自动收费；待更新仍为已保存，关联行动仅在用户明确保存后成立。
