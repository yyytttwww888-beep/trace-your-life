# M3 第六阶段：有界综合与行动实验

依据已确认的[可靠性协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)及[主设计](../superpowers/specs/2026-10-16-personal-knowledge-and-reflection-design.md)，继续实现新的综合判断与用户选定行动的回看。前端后置。

## 取舍与范围

综合直接对范围内多条原始片段进行对照，复用请求预算、证据台账和独立核对。采用独立 `SYNTHESIS` 调用目的，避免把整理覆盖与综合覆盖混算；提案均为待确认解释。核对必须重新取得该批全部原文，包括没有被结论选为支持的上下文。只有用户确认并通过核对后才能发布洞察。

大范围按稳定顺序和预算分批；成功进度持久保存，失败可显式继续，在途调用显式恢复。预算超限先在派发前减少片段，仍不适配则停止。单批包含全部可读文字与多批仅分别完成材料对照是不同状态；本阶段不把多个局部判断冒充一份跨批全周期综合。后续摘要综合图需要独立的依赖与反馈协议，此次不通过聊天历史传递摘要绕过它。

数值继续由现有指标接口计算。当前综合不生成健康统计、改善率或成长分，模型可引用的类型化指标协议后续另行扩展。报告材料视图与新综合提案分别查阅；保存或导出综合提案不重新调用模型。

行动实验是用户明确提交的独立内容，包含触发情境、具体做法、预期信号、回看日期及时区。可以关联当时有效知识的身份，但不自动复制模型建议或自动采纳。每次回看区分执行、未执行和未知，保存观察结果，以及继续、调整、停止或暂缓决定。修改计划和回看追加修订，保留旧计划及历史结果；来源后来删除不删除用户行动。

行动使用同一主库的修订链、当前指针与永久删除台账，数据库升级至 v6。完整备份升级至 v5，兼容旧格式；恢复时删除优先，同身份目标库整条行动历史优先，不能被旧备份回滚。行动变更递增分析代数，不冒充已纳入原始记录的 AI 证据。阅读包单独导出有明确筛选范围的行动，证据包不混入行动。

## 验收与交付

- 综合验证多原文输入、实际请求预算、分批继续、Unicode 长文尾部、来源与期限变化、不支持解释不能当自述发布、核对全部上下文，以及提取／综合覆盖隔离和旧任务载荷兼容。
- 行动验证明确采纳、CAS、重复调用、历史、时区到期、未知执行状态、来源删除仍保留用户文字，以及备份往返、旧格式、本地优先与删除不复活。
- 执行相关及全量离线测试、lint、APK 构建。新综合提示词使用合成资料独立验证；真实调用结果与替身测试分别报告，凭据留在仓库外。
- 代码、接口文档及实现状态进入基于上一阶段的草稿 PR；不合并 PR，不接入新页面。

## 实际结果

2026-10-17 完成独立综合调用及原文分批处理器、行动服务／修订链、数据库 v6 迁移、备份 v5 和当前行动阅读导出。任务载荷 v4 保持 v1–v3 兼容，外层备份保持 v1–v4 兼容。原文元数据清点逻辑供提取与综合复用，两个目的的处理覆盖单独计算。

新增 50 项离线行为测试：综合执行协议 11、分批综合 12、行动服务 13、行动存储／恢复 8、行动数据转移 6；另增 1 项显式真实综合测试。全量 362 项中 359 项通过，3 项真实 API 测试默认跳过；lint 无错误、2 项既有升级提示，APK 构建成功。审查补充了模型返回期间任务被删除的状态转换，防止抛出无解释的异常或重新保存已删除任务。

使用用户已配置的仓库外 KEY 单独运行真实综合验证，1 项通过、0 失败、0 跳过，共 2 次请求，无重试。两条合成学习记录生成 2 条待确认解释；一条同时引用两份原文，独立核对重读全部输入并返回 SUPPORTED。实际用量及边界见[DeepSeek 验证](../DEEPSEEK.md#综合真实调用验证)。没有使用真实个人记录，也未自动采纳行动。

行动单修订上限为 128 KiB，以容纳合法最大长度计划、被回看的旧计划与结果；总上限仍为 16 MiB。测试验证最大文字及 JSON 转义后仍可保存，合并超过总上限时恢复原子失败。新页面、真机、跨批统一综合、自动反例检索、类型化模型指标和行动内容的模型取证仍待后续实现。
