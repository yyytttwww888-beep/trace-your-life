# M4 第一阶段：看板数据、行动回看与导出

用户要求继续下一步实现，并维持功能优先、前端后置。本阶段落实[主设计的看板章节](../superpowers/specs/2026-10-16-personal-knowledge-and-reflection-design.md#8-数据看板关键趋势与行动回看)，复用已有记录指标、正式洞察及用户行动；不新增模型调用。

## 交付与取舍

提供可重建的看板快照和分页接口，固定来源版本、分析代数、评估时刻、时区及到期时间。采用读取现有主存的聚合视图，不另存一份统计主库，也不进行数据库或备份格式迁移。请求可指定有序、去重的 1–3 项关注指标；默认睡眠、运动、饮食，当前明确显示来源尚未接入或缺少可用结构化输入，数值为空。看板始终提供当前／前期的资料覆盖辅助区，可选择把记录覆盖加入主要图表卡；它和健康卡片的数值及依据分开。用户偏好的持久化随页面阶段完成。

支持最近 7／30／90 天及显式历史截止日，未来截止日拒绝。7／30 天按日显示，90 天按自然周汇总，首尾不足整周保留实际日期和天数；包含当天的部分标记进行中。记录覆盖沿用 `record-coverage` v1，区间和未知日期单列，不摊到图表点。每个点下钻只返回真正贡献数值的单日记录，其他候选通过独立类别入口定位。

同时计算前一个等长窗口，保持同一来源快照。仅当本窗口全部为已结束日期时提供精确日期记录数与记录天数的差值，且明确比较的是已保存记录；进行中窗口只并列展示范围与覆盖，不生成完整周期的改善判断。未知时间可能同时出现在两个候选集合，不能把候选总数当作活动变化。

指标解释只读取已经发布、当前有效、来源／范围／口径／数值完全匹配的指标洞察；同日期的显式 ID 子集或不同归档范围不混入。缺少解释时返回空，不暗中调用 DeepSeek。解释和来源均分页，不把知识库装入一个响应。

## 行动与有效性

行动区展示当前全局行动，不以趋势日期窗口隐藏过期未回看的计划。到期按行动自身时区计算；停止、尚未到期、待回看分别呈现。最近执行结果读取历史中最近一次实际回看，普通编辑不会抹掉已回看的状态，未回看与明确未知分别表示。

时间线采用“采纳”和“回看”标记；创建时间不冒充实际开始或执行时间。回看使用当时被回看计划的日期标签与时区，点击可定位对应修订。日期窗口只限制标记，不限制全局行动区。

任何资料、知识、反馈或行动修改使快照失效。有效期不晚于看板时区及相关行动时区下一午夜，且不晚于纳入洞察或有效行动来源的最早到期时刻；没有数据库写入也能拒绝过期结果。全部分页和叶子读取前后检查条件，冻结调用者集合。返回条数及生成容量有明确上限，超限失败，不静默截断。

## 导出

提供 `trace-life-dashboard` v1 ZIP：Markdown 概览、版本化元数据、当前／前期 CSV、分页来源目录、洞察定位及全局行动摘要／标记。仅 CSV 中的程序日期、数值及生成身份进入表格；用户文字不进入 CSV。保存口径和来源修订，导出不复制原文正文、照片、反馈正文、回看观察正文、任务台账或凭据，不是完整恢复备份。

文件内容保持固定评估时刻的历史快照，不能作为可绕过产品协议的模型凭据。沿用受控暂存、校验清单、无覆盖原子发布与中断回收，最终提交同时核对来源、分析代数和有效期。

## 验收

- 7／30／90 天、跨月、闰日、夏令时、自然周边界和进行中窗口；空数值／空记录、未知与区间、前后期一致口径。
- 图表下钻严格只含贡献者；过窄洞察不挂到整个图表，反馈／期限变化阻止旧解释。
- 行动编辑后保留最近回看，时区与停止状态正确，旧计划回看及采纳标记不冒充执行事实。
- 来源、行动、反馈变化与单纯跨午夜均拒绝旧快照和旧导出；分页有界、内部链接与文件清单正确、目标不覆盖、正文不夹带。
- 运行相称行为测试、lint、APK 构建和 GitHub CI；本轮没有模型协议变化，不重复付费 API 测试。
