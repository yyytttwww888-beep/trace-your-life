# M1：离线记录与复盘模板实施计划

用户已要求按现有设计逐步实现，暂不进行页面视觉设计。本次交付可构建的 Android 应用、基础操作入口及行为测试，范围对应路线 M0 的应用基础与 M1；后续备份、AI、看板和外部接入仍按路线推进。

## 技术与职责

- 原生 Kotlin，单一 Android app 模块；界面只使用系统控件验证功能，持久化与业务规则不放在 Activity 中。
- `model` 保存记录时间、修订、模板及附件的类型；`templates` 负责内置问题与非执行式文本解析；`storage` 负责 SQLite 事务、模板版本、修订、删除和受管附件；Activity 调用这些职责。
- SQLiteOpenHelper 管理版本化数据库，应用内部持久目录保存附件。保存记录与变更任务同事务；旧版本与当前版本可分别读取；更新带预期修订检查。
- AGP 8.11.1、Gradle 8.13、Kotlin 2.2.21；compile/target SDK 36，min SDK 26。构建与测试运行于已安装 JDK 21，字节码目标 17。Robolectric 4.16 原生 SQLite 测试覆盖 API 35/36，实际执行情况记录在交付说明。
- 固定构建依赖与 wrapper 校验值；本机 SDK 路径和代理配置不提交。应用不申请网络权限，不把尚未接入的 AI 表示为可用。

官方兼容依据：[AGP 8.11](https://developer.android.com/build/releases/agp-8-11-0-release-notes)、[Kotlin Gradle 兼容表](https://kotlinlang.org/docs/gradle-configure-project.html)、[Robolectric 4.16](https://github.com/robolectric/robolectric/releases/tag/robolectric-4.16)。

## 实施顺序

1. 建立可重复构建的 Android 工程、私有数据存储与系统备份排除配置。
2. 实现稳定身份、日期／区间／未知时间、多主题、分页筛选、修订、归档、删除与变更登记；添加持久化和失败场景测试。
3. 实现内置深度复盘、文本／Markdown 模板解析预览、模板修订与旧复盘绑定；导入文本视为资料，不执行其中指令。
4. 接入最小操作入口：保存、查询、编辑、历史、归档／删除、按模板填写及导入模板；保留未提交输入应对界面重建。
5. 验证受管附件的提交、引用与删除；模型分析留待后续阶段。
6. 运行测试、Android lint 和 APK 构建；更新 README、路线、AGENTS 中的实际状态，提交功能分支。

## 验收

- 保存后关闭并重新打开数据库，原文、发生时间、主题、问题与答案保持一致。
- 补记按发生日期查询；未知时间保持未知；区间与筛选范围相交时可找到记录。
- 模板更新后，已有复盘仍显示原问题与答案；可选问题未填写不会被编造。
- 同一身份更新递增修订；过期编辑拒绝覆盖；正文与变更任务一起提交。
- 归档资料保留历史；删除清理正文及修订，保留无原文的删除标记，已删除 ID 不被重用。
- 附件在引用提交前完整保存；仍有有效引用时保留，无引用时回收；失败不会留下指向半份文件的记录。
- 简单入口能完成新增、编辑、复盘、模板预览及筛选；自动测试与真实手机验证分别报告。

## 已知阶段边界

本次不提供完整恢复备份、AI 取证或分析、趋势看板、长期画像与华为接入；不将持久化变更队列称为已完成后台分析。资料导出和恢复必须在 M2 完成，当前调试版本只用于功能验证。目标手机型号与系统版本尚未取得，构建成功和 Robolectric 测试不代表真机验收通过。
