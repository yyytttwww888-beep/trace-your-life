# 跨期经验、历史意见与分析归档实施

依据：[行为设计](../superpowers/specs/2026-10-20-experience-memory-and-archive-design.md)。

1. 增加经验线索和固定修订事件主存、备份恢复与删除台账；接通主题、知识详情及变化过程。
2. 为普通分析建立历史意见目录、预算内内容读取与版本凭据；在每条发现发布前执行分页人工语义检查，接通纠正输入及检查界面。
3. 增加任务归档状态、独立容量和元数据分页；接通归档、恢复及已归档列表，保留知识发布与删除传播。
4. 将经验线索加入阅读包分页导航，严格使用同包知识引用，报告缺失和省略，不复制范围外或被删除正文。
5. 运行与变更相称的自动回归，再完成旧安装升级和合成数据的 Android 操作验收；构建与发布新预览 APK，记录真实结果。

模块分工：经验 Store/service/UI；历史意见读取/核对/发布门槛；归档及公共主存/迁移/备份；入口页面、阅读导出、文档和最终整体验证。共享主存由单一实施者修改，避免并发覆盖。


## 完成与验证

上述五项已实现；三名 Agent 分工完成模块，并对删除、恢复、范围导出和用户保存门槛复核。最终测试、模拟器真实 DeepSeek、备份与导出、APK 身份及未验证边界统一见[开发验证](../DEVELOPMENT.md#跨期经验与历史意见验证)。设计中的经验关系由用户明确选择；历史意见的语义对照由用户完成，尚无自动全历史扫描。
