# 行动周期归并与可移植知识包

用户已选择实现行动分析跨批汇总及行动分析知识包导出，继续先后端、后前端。产品约束沿用[主设计](../superpowers/specs/2026-10-16-personal-knowledge-and-reflection-design.md)、[检索协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)及[行动证据](../ACTION_PERIOD_REFLECTION.md)。本文件记录本轮设计、实施及实际验证。

## 设计与取舍

复用已有分层归并和独立原文核对，扩展其中的来源类型；不建立第二套报告系统。直接拼接所有批次会绕过预算，另建行动专用归并系统则会重复维护删除、恢复和发布规则。同一任务仍固定范围、快照、全部行动凭据目录及共享请求额度。

1. 行动任务的成功 `ACTION_SYNTHESIS` 批次成为归并叶，包含空输出批次。记录和行动凭据分别登记、去重及计算处理覆盖，多个行动修订不能被解释为多个独立实验。全部输入完成后，2–4 个子节点逐层归并；只有包含全部成功叶的当前根才表示完成跨批整合。
2. 草稿正文不等于正式洞察。核对每条根陈述时扫描完整记录与行动来源链，每批合计最多 32 个输入；最终必须重读全部相关来源。必要上下文不足、直接反例、相关来源超过 32 项或实际请求预算不足时，保留草稿和进度并阻止错误发布。用户确认和模型支持仍分别要求。
3. 行动来源沿用 `OPENING_PLAN`、`PLAN_CHANGE`、`USER_REVIEW`；区分旧计划、执行自述与下一轮计划。扫描及归并不把摘要当原文，不把无回看当失败。原文下钻、来源变更、祖先反馈、删除、恢复及条件发布共同处理两类证据。
4. 分析内部格式升级至 v11，知识内部格式至 v6；旧纯记录证明的编码及哈希保持稳定，旧格式不能伪装支持新的行动归并证明。数据库和外层备份结构没有新增字段时不升版。

## 阅读包行为

`KNOWLEDGE` 包纳入通过现有有效性检查、范围检查的已发布行动洞察。由知识正文导航到分页行动证据目录，再读取固定行动修订的唯一 Markdown 正文及程序 JSON；完整扫描来源链与最终核对实际读取分开标记。只导出纳入知识所需的行动凭据，不复制全部行动历史。草稿和未确认提案不进入正式知识区，原始 `EVIDENCE` 包维持已有范围。

日期导出必须包含知识的完整分析周期。期初计划可作为明确标注的周期前背景纳入，仅包含当时计划，不携带上周期回看；晚补记的回看按 `reviewedOn` 归属，保存时间单独显示。当前行动计划按 `reviewOn` 筛选的原有功能与这些证据分别统计。行动没有主题时，带主题限制的导出保守省略该类知识并记录原因，不推断行动的主题归属。

导出绑定同一快照，验证历史修订内容哈希、全部原文引用、分页导航与文件清单，发布时重新检查来源、分析代数、删除和有效期。输出是生成时的历史阅读包，不能恢复应用数据，也不能强制外部 AI 遵循读取预算。完整加密备份继续负责恢复；周期材料包本轮保留其明确的行动知识省略说明。

## 实施顺序与验收

- 扩展归并依赖、处理器、双类型扫描和最终核对、知识证明与持久化验证。
- 扩展 DeepSeek 请求适配，保证行动归并最终核对保留扫描约束；即使某批没有行动正文，仍保留行动任务语义。
- 完成知识包的行动证据索引、唯一正文、范围与哈希校验，以及包含／省略说明。
- 覆盖纯行动与混合资料、多层归并、完整覆盖、空输出、失败续跑、未扫／重复扫／反例／预算阻断、反馈与来源修改、删除传播、旧格式兼容、备份恢复、知识包链接和最终发布竞态。
- 运行相关行为测试、全量离线测试、Android lint 与 APK 构建；在已有授权下使用仓库外 KEY 和明确合成资料进行有上限的真实 DeepSeek 验证。真实调用、离线协议和手机验证分别报告。

## 范围边界

不新增页面、不自动确认或采纳行动、不扩大请求预算、不实现健康接入或餐食照片识别。跨批整合是草稿覆盖状态，不保证模型理解、反例召回或真实生活资料完整；最终核对装不下时仍需保留未完成状态。
