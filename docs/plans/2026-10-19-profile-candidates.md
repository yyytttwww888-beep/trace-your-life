# M4 第三阶段：受控画像候选生成

用户继续实现下一阶段功能；本轮沿用已确认的[画像设计](../superpowers/specs/2026-10-16-long-term-personal-profile-design.md)、[受控检索协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)及功能优先的顺序。餐食照片和新增前端继续后置。

## 方案与边界

在已有 `AnalysisRequest` 中保存类型化 `profileTarget`，每个任务固定一个维度与层次。复用 `SYNTHESIS → REVIEW` 的原文分批、预算、调用台账和整批重读；随后显式选择通过确认的陈述发布为共享洞察，再创建引用该固定知识版本的画像候选。

相比新增一套画像专用调用、输出和证据协议，复用综合流程可以保持原文核对、失败恢复和删除传播一致。只在问题文字中约定画像目标则不能可靠恢复或限制任务类型，因此目标单独持久化并严格校验。现有采用和历史接口继续维护画像，不复制第二份机器正文。

本轮目标仅支持 `RECENT_STATE` 和 `CONTEXTUAL_PATTERN`。`LONG_TERM` 在结构层拒绝；跨周期长期推断、画像摘要发布、自动反例检索、跨任务同义反馈治理和 Android 定时维护另行实施。手工组织已有知识为长期层次的能力不受影响，但不表示自动验证了长期稳定性。

## 生成与核对

- 请求固定日期、时区、指定 ID 范围、预算与到期时间。画像维度是组织目标，不用主题标签排除未分类来源。
- 画像任务仅允许综合和普通原文核对；不能在同一目标下混入提取、指标解释或派生归并。
- 执行器与 DeepSeek 适配器采用明确的画像提示：保留情境、自述性质、反例、替代解释和资料缺口；不得推断人格、诊断、能力等级或计算未提供的统计值。
- 每批只读取登记的原文片段；旧画像、用户采用决定和画像注释不作为原始证据。全部新陈述均为待确认解释，允许空提案。
- 独立核对重读生成批次全部原文，包括未被模型选为支持引用的片段；预算不足不能删掉反例后继续。
- 默认每批 1 个原文片段；显式扩大批次须给后续整批核对预留输入预算。候选和反馈长度仍可能超限，报告预算不足并保留进度，不缩减核对范围。
- `process` 共用本轮请求上限，先核对已有待核对提案，再生成下一批；不自动确认、不发布、不采用。失败与取消保留进度，重新执行复用成功调用。
- 元数据页报告范围、处理覆盖、当前候选状态及多批尚未整合；正文和证据按叶子读取。明确 `counterevidenceSearchExhaustive=false` 与跨任务语义去重未完成。

## 发布与画像候选

用户确认沿用独立反馈接口。显式 `materialize` 要求当前任务、预期版本、用户确认与匹配当前反馈版本的支持核对，才能发布 `INSIGHT`，随后保存为 `CANDIDATE`。确认会改变反馈版本，需以该版本重新核对；自动采用仍被禁止。

物化桥接使用稳定身份和仓储事务；重复执行不新增洞察／画像修订。已有画像的采用决定与独立文字保留；固定知识引用不同则要求明确维护，不能自动改绑。流水线创建的稳定画像 ID 被删除后不能换 ID 恢复；现存同知识、同维度、同层次的手工条目也不被覆盖。

本阶段不建立跨任务语义抑制台账。已永久删除的手工自定义画像 ID 不保留原组织位置，无法据此识别后来显式选择的同义候选；不宣称解决这种历史语义去重。新候选始终需用户明确确认、物化和另行采用，不静默恢复旧的默认画像。

来源修订、删除或任务到期使旧任务生成和物化停止。反馈变化使相关旧核对失效，否定、纠正、撤回或删除反馈阻止对应候选物化；其余未处理批次仍可继续。共享知识失效沿现有关系使当前画像退出。时钟回拨到任务更新时间之前也不能继续派发或物化。用户独立文字继续按既有保存与删除规则维护。

## 持久化与验证

分析内部载荷升为 v8，新增可空 `profileTarget`，严格兼容旧 v1–v7；旧版本夹带目标字段拒绝。普通旧任务不自动解释成画像任务。完整备份仍为逻辑 v6／schema v7，画像载荷仍为 v1；现有加密备份保留新任务与目标，阅读包继续省略提案和未采用画像。

验证覆盖目标和目的限制、旧版兼容、完整请求预算、整批核对反例、重启与幂等、共享请求上限、用户确认与采用分离、并发及删除失效、固定引用冲突、备份恢复与导出。运行全量离线测试、lint、APK 与 GitHub CI。

另提供默认关闭的 `DeepSeekProfileLiveTest`：最多一次生成和一次独立核对，使用明确标注的三条合成资料与仓库外既有密钥，无自动重试。测试在生成后模拟用户确认，再执行当前反馈版本的独立核对与物化；仅验证这一有界案例，不作为总体画像准确率或真机验收。
