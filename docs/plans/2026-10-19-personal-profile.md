# M4 第二阶段：画像采用、维护与迁移

用户要求暂不实现餐食照片分析，继续功能开发；按既有[画像设计](../superpowers/specs/2026-10-16-long-term-personal-profile-design.md)和功能优先、前端后置的顺序，完成已有知识的画像采用与维护。本轮不新增模型调用，不将已有画像作为新证据，也不实现自动人格概括。

## 方案与范围

沿用既有设计，画像条目只保存观察／洞察的固定 ID 与修订、八个维度之一、长期／情境／近期层次、用户采用状态及独立用户文字。陈述和证据由共享知识维护，避免复制后出现不同版本。直接保存一份画像自由文本会失去依赖关系；一次实施自动生成、跨任务反例搜索和后台调度则涉及独立协议与验收，留待后续阶段。

本阶段接受已经发布的 `OBSERVATION` 和 `INSIGHT`，排除普通知识条目；洞察继续遵循原有确认门槛。画像创建为候选，采用由用户显式决定。保留候选、采用、不采用与被替代状态；改绑知识版本回到候选，不能自动跟随最新知识。层次是用户的组织选择，不代表程序验证了长期稳定性。

“不用于画像”只影响采用状态，不能自动否定共享陈述；解释错误或成立范围过宽继续通过共享反馈及新知识修订处理。画像注释不能暗中改变原陈述。独立用户文字保存在画像修订中，元数据维护不丢弃它；历史文字可查看，本阶段永久删除以整个画像条目为单位，清除全部修订并写墓碑，不提供单段反馈的永久删除入口。

## 当前视图与证据

读接口将用户采用状态、关联知识是否为当前有效修订、近期窗口状态分别表达。默认当前区仅包括已采用、知识当前有效且在适用窗口内的条目；候选、不采用、失效和历史须明确查阅。近期采用默认 30 天查看窗口，可在有界请求中调整；窗口按查询时区日期与知识范围交集计算，移出后不再作为当前状态。长期内容仍显示原有范围和证据，不输出人格得分。

八维概览返回数量、未知和更新时间，不生成新的总结判断。维度、条目及修订分页，正文与证据按需读取；资料、知识、反馈和画像修改使旧快照失效，跨日、知识过期和时钟回拨也校验。所有这些接口仅供受信任应用调用，模型继续使用既有受控取证协议。

新建、换源和采用在保存事务内检查知识修订及有效性。失效后仍允许不采用、补充用户文字、查阅历史和删除。幂等操作重试不新增修订；并发旧版本写入拒绝。容量明确有界，超限整笔失败。

## 主存与迁移

schema v7 新增画像修订、当前指针与删除台账，写入仅推进分析代数；画像关联使用软引用，知识删除不级联删除用户独立文字。完整备份升为逻辑 v6、画像内部载荷 v1，兼容旧 v1–v5；画像历史、采用决定、独立文字和墓碑一并保存。

恢复先验证完整结构与修订链，再合并双方墓碑；同 ID 的本地完整画像链优先，旧备份不能覆盖本地拒绝或用户文字。缺失的知识修订允许作为不可用身份保留，不能因此丢弃用户内容，也不能把它显示为当前依据；存在的引用须为允许的知识类别。旧版备份同样保留目标画像，只有画像的目标库也视为非空并要求显式替换。

知识阅读包新增 `profile/` 分维度分页入口，引用同包已经纳入的共享知识。只导出当前可用且已采用的条目；范围之外、候选、失效及未纳入知识的条目省略并计数。证据包不包含画像。画像独立用户文字和完整历史仅进入加密备份，不夹带到普通阅读包。生成视图不构成新的 AI 画像发布版本；专门的画像发布历史及自动摘要后续实现。

- 阅读包范围与知识成员严格匹配；分层导航、链接、分页与校验完整，无机器正文重复及独立反馈泄漏。
- 运行行为测试、lint、APK 构建与 GitHub CI；没有模型调用变更，不重复付费验证。
