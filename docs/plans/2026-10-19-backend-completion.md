# 后端闭环：行动复盘、纵向画像、增量整理与看板偏好

用户已明确要求完成上一轮提出的四项后端。基线为 `feat/profile-maintenance` 的 `3b1af4b`，前端、华为接入与餐食照片不在本轮范围。沿用主设计、受控检索协议及画像设计；不新增未经登记的模型读取通道。

## 方案与分工

选择扩展既有受控分析协议，并保持四个独立应用接口。把行动复制成普通随记会混淆计划与实际、增加重复证据；另建一套模型与存储链则会重复预算、纠错和删除机制。因此行动使用独立证据类型，画像复用原文协议，后台只编排受控任务，偏好作为独立设置保存。

四项并行实施；共享任务编解码由行动模块统一集成，纵向模块提供目标解析和资格检查。主库迁移、偏好、备份外层与应用入口统一整合。仅主 Agent 运行 Gradle，防止并行构建或未完成文件导致验证混乱。

## 行动与周期复盘

增加行动证据目录：选择周期开始时仍进行的计划、周期内计划变更，以及按实际回看日期归属的回看。目录只保存固定修订身份和摘要，模型按登记叶子读取用户填写的计划与回看；原计划、执行情况、观察和调整后计划分别表达。

行动与原记录可在一次有界综合中对照；每批总输入受现有 32 项与完整请求预算限制。核对重新读取整批原文和行动证据，用户确认后才可发布洞察。没有回看和回看后仍未知分别保留，选择行动不等于执行，单次改善不能证明因果。

按批输出支持完整范围分页、取消与续跑。只有单次请求涵盖本范围全部输入时才能说明完整有界对照；多批结果保留尚未统一整合的状态，不冒称整体周报。过长单项明确停在预算边界。发布后的行动依据随知识保留，行动修订使关联结果失效，删除及恢复清理机器派生内容。

## 纵向画像与变化摘要

调用方明确指定维度及多个连续、不重叠的比较周期。周期数量是比较结构，不是人格稳定性的科学阈值。生成按周期选取有日期的原文对照；结论和最终支持须覆盖至少两个不同周期，未知或跨周期日期不能充当独立周期支持。

大范围沿索引分批，不一次灌入全部历史。每个候选保持实际读取范围和引用，全部候选仍须经过固定范围完整反例扫描与历史反馈检查；相关原文过多时停止，不截断反例。长期候选即使没有旧画像也必须完成维护核对，由用户确认并明确保存，采用单独执行。

变化摘要从既有修订确定性产生，区分知识引用、组织、采用和独立文字变化。目录分页，按固定身份读取前后修订；不把采用操作当作成长，也不重建已经删除的文字。

## 后台增量整理

默认关闭。明确启用后接收之后新增或修订的记录事件；暂停保留队列，停用后重新启用从新的授权起点开始。原始记录仍先可靠保存，后台发现事件不依赖页面常驻。

本机操作库保存策略、事件游标、作业、派发预留和失败状态；不随个人备份迁移。每轮、每日和每个作业分别限制模型请求，派发前持久预留，失败或进程中断不退款。暂停在每次派发前检查；无法撤回已发送请求。失败不自动付费重试，遗留在途任务要求显式恢复。

Android 持久调度负责联网、电量及唯一工作约束；领域任务仅执行提取与核对，不自动确认、正式发布或采用画像。本阶段只自动处理原始记录，高层行动／纵向综合仍显式启动。现有全库来源版本变化可能使任务重建，累计请求上限不能因此重置；不宣称已支持无关分支的细粒度调用复用。

恢复事务推进本机恢复代数；后台发现变化后停止旧调度授权并要求重新启用，避免旧备份触发意外云端发送。操作库配额记录仍按本机日界限管理。

## 看板偏好

保存 7／30／90 天窗口、时区、1–3 个有序指标、关注维度及归档选项。严格校验重复值和无效枚举，按版本更新，重启后可读；默认偏好与健康来源是否可用分别管理。

偏好进入主库及完整恢复备份。目标库已有明确设置优先，空目标可接受备份设置；重置也留下新的设置版本，旧备份不能覆盖用户重置。偏好不改变原始记录及指标口径，使用保存的偏好创建看板时仍受快照和时间检查。

主库升级至 schema v8，完整备份外层升级至 v7；严格读取旧版本。分析与知识内部载荷由新证据协议单独升级，旧画像维护计划的摘要保持兼容。

## 验收

- 行动：计划与执行隔离、周期基线、补记回看、未知、全批核对、预算、重启、在途修改、删除和恢复、本地行动链优先。
- 纵向：多周期身份、日期缺口、重复来源不增证据、跨期对照、完整扫描、空目录维护门槛、确认与采用分离、变化分页和删除失效。
- 后台：首次启用范围、重复事件、暂停／停用、持久额度、请求失败不自动重试、崩溃恢复、来源变化、备份恢复停用和 WorkManager 唯一工作。
- 偏好：默认、保存、版本冲突、重启、非法设置、重置、旧库升级、加密备份往返及目标设置优先。

完成后运行相关行为测试、全量离线测试、lint、APK 构建及 GitHub CI。真实 DeepSeek 如新增评估，使用合成资料和仓库外密钥，显式限定请求数量，结果与离线测试及实体手机验收分开记录。
