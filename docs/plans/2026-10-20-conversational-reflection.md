# 对话式回看实施计划

依据[已确认设计](../superpowers/specs/2026-10-20-conversational-reflection-design.md)。

1. 增加本地日期／意图规划与对话工作流：自由问题、明确范围、追问目标、独立分析任务。
2. 为派生追问背景登记有界引用；扩展分析协议及依赖失效、删除和发布检查。
3. 增加持久对话元数据和分页读取，扩展备份、恢复与阅读包；独立问题与机器回答分开保存。
4. 新增原生问答入口及历史，接通范围预览、继续分析和已有依据／核对保存页面。
5. 运行行为测试、完整回归、lint、APK；使用合成资料验证实际 DeepSeek 与模拟器，再更新文档和交付预览 APK。

重点失败场景：相对日期冻结、歧义不静默执行、失效父回答、反馈竞态、删除传播、旧备份恢复、重复提交、预算含所有背景、页面重建不自动调用。实现状态与实际验证以开发文档记录为准。
