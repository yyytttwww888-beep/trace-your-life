# M3 第八阶段：周期草稿原文核对与发布

延续用户已确认的后端优先安排及[检索与可靠性协议](../superpowers/specs/2026-10-16-knowledge-routing-and-reliability-design.md)，将上阶段周期草稿接到正式知识发布。前端仍后置。

## 设计

目标固定为根节点身份、陈述序号和摘要。程序沿完整来源链取原文清单，分批重读每个唯一原文片段，要求模型逐片段标记支持、反例、必要上下文、无关或上下文不足；扫描本身不作整体支持判断。成功扫描不可按另一批次键局部重做，以免反例在反复选择中消失。

全部片段扫描后，最终核对必须重新读取全部未标为无关的原文，同时提供扫描意见与未知项。存在上下文不足、无相关原文、相关原文超过 32 个或实际请求预算时保留进度并阻止发布，不截断。扫描已标记反例时，不接受最终支持。最终模型独立核对原陈述，不能把局部结果相加当作整体正确。扫描的相关性判断仍可能出错，处理覆盖不等于客观事实或生活记录完整。

独立用户确认、原文扫描覆盖、最终核对意见分别保存。只允许将当前支持且用户确认的原陈述发布为洞察，复用现有知识库修订、目录、导出和行动来源。发布从任务台账重建证明，在事务中检查来源、期限、任务版本、当前根的完整叶清单、扫描及最终调用身份、自己与全部祖先反馈。所有祖先归并陈述也纳入反馈依赖，包括尚无反馈的版本 0。

永久删除反馈清理相关后代模型正文、核对结果及所有受影响的知识历史，保留删除墓碑、调用预算和必要纯身份。用户独立反馈与行动文字继续保存；恢复合并删除信息后不能使被清理的内容复活。旧图保留原身份规则，若后来出现其未登记的祖先归并反馈则失效。内部分析与知识载荷分别升级，数据库及外层备份版本按是否改变结构决定，不为了内部载荷重复迁移表。

## 验收

1. 扫描严格限定完整根清单中的原文，拒绝重复、漏项、伪造引用和派生 ID 冒充证据；最终原文由程序决定。
2. 编排可限定本轮调用数、取消、预算缩批和重启续跑；实际供应商输入与台账预算一致，失败不自动重试。
3. 覆盖自身确认、所有祖先反馈变化、版本 0 后新增反馈、新叶、来源修订、期限与并发发布；旧核对不再有效。
4. 发布、读取、导出、行动、备份恢复共用依赖判断；父反馈删除影响整条知识历史且独立用户文字保留。
5. 严格新载荷校验及旧版本兼容；资源超限明确拒绝。
6. 运行相关与全量离线测试、lint、APK 构建，再用有明确请求上限的合成资料执行真实 DeepSeek 扫描及最终核对。提交堆叠草稿 PR，不合并。

## 后续边界

本轮不含模型指标引用、库外自动反例检索、后台调度、跨任务反馈合并、长期画像、健康接入与前端。当前任务来源链之外的相关性与反例不作穷尽声明。

## 实际实现与验证

2026-10-19 完成扫描与最终核对协议、可续跑处理器、DeepSeek 独立提示词与解析、用户反馈、知识条件发布及导出／恢复维护。分析写入 v6、知识写入 v2；数据库仍为 v6、外层完整备份仍为 v5。旧 v5 成功草稿直接复用，失败与中断任务通过新版计划键继续；删除反馈后的旧调用键不可再次生成正文。

测试覆盖 40 个原文片段逐批扫描后最终只重读全部 2 个相关片段，并保留另外 38 个分类与原始引用；漏扫、重复扫、缺上下文、反例、超过 32 个相关片段及实际预算不足均阻止错误发布。祖先反馈版本 0 后新增反馈、自己确认变化、后来成功综合叶、较晚反对意见与派发竞态分别影响当前结果；删除及恢复保留独立用户文字和行动。

容量维护另覆盖近 2 MiB 的合法 v5 历史和近 16 MiB 的任务集合：清理身份扩容无法保存时，原子清理关联任务与知识并返回明确结果；完整恢复先排除反馈不兼容任务、完成所有清理，再决定最终总量是否需要清理任务，不因执行顺序丢弃本可保留的分析。

真实 DeepSeek 的 1 项合成资料验证通过，0 失败、0 跳过，共 2 次请求、无重试。扫描 2 个原文片段，最终独立重读全部 2 个相关片段，生产发布事务保存 1 条已确认洞察。扫描用量为 1,339 输入／240 输出 token，最终核对为 2,186 输入／171 输出 token。原文综合与草稿由测试构造，用户确认由测试显式模拟；本次不代表提取或归并质量、反例召回率、总体分析准确率或实体手机验收。入口与保护见[DeepSeek 说明](../DEEPSEEK.md#周期原文核对真实调用验证)。

全量离线验证共 464 项，459 项通过、0 失败、5 项显式真实 API 测试默认跳过。本阶段新增 57 项离线测试及 1 项真实 API 测试：协议及升级 12、续跑编排 12、DeepSeek 适配 4、知识发布 14、转移维护 11、容量维护 4。Android lint 无错误、2 项既有依赖升级提示；调试 APK 构建成功。真实测试另行显式运行，未在普通测试或 CI 读取 KEY。
