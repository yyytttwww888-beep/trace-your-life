# 主题阅读、关联建议与完整回看流程

用户已确认实现上一轮列出的七项优化。本轮沿用已有 Android 本地主存、受控分析协议及单色界面；餐食照片继续暂缓，华为授权和实体手机长期验收不以模拟数据代替。

## 设计选择

在现有可靠模块上接通完整使用流程。主题概况和查找使用本地可重建视图，展示已有知识及其依据，不借摘要凭空生成更强判断；需要新的解释时仍从受控原文分析发起。关联候选先使用本地主题与文字检索，提供可解释的匹配理由，不将检索相似度称为已确认的语义关系。历史意见比较确实调用有界模型扫描，最终用户决定与原文支持核对分别保存。

相比另建独立全文副本，这个方案让删除和修订直接作用于主存读取；相比将全部任务都交给一次模型调用，它能保持固定范围、分页、完整输入预算及清楚的覆盖。新页面复用 Ui / ScreenActivity，不替换技术栈或增加装饰。

## 七项交付

1. **主题概况**：从主题进入“目前留下的理解、需要关注、正在尝试、近期积累、待更新”。已有陈述保持原文和固定知识修订；不把记录数量称为问题频率或成长。每节有限条目并能进入完整列表、知识和行动。展示日期范围及来源状态，没有资料时说明缺口。
2. **归类与经验关联建议**：自由记录可根据正文和已使用主题取得可选标签建议，保存仍由用户选择；知识加入经验时优先展示匹配的既有线索及匹配依据。相似文字只用于推荐候选，补充／例外／收窄／替代仍由用户明确决定。未分类记录继续可查。候选分页扫描，仅保留有界排名，正文不进入新模型通道。
3. **行动复盘**：普通分析范围页、行动页和周期回顾可进入同一行动分析流程，分别读取计划、实际回看和原文，接通生成、多批归并、原文／行动证据查阅、扫描、核对和确认后保存。复用既有后端，缺材料保持未知。
4. **历史意见辅助对照**：逐批比较全部相关意见，保存模型建议、理由、读取编号及覆盖；冲突／不确定优先可见。用户可明确采纳当前展示页的安全建议，不能自动将模型意见记为用户决定。未扫描、未确认或冲突继续阻止发布；对照改变后重新核对原文。使用任务载荷 v13 保留旧协议读取，外层主存不必为导航另存一份正文。
5. **长期画像与维护**：接通已有跨周期生成、关系比较、反例扫描、最终核对与明确新增／收窄／替换。待采用、采用和历史状态独立；历史任务和进度可恢复，采用不由模型自动完成。
6. **查找与更新**：本地跨原始记录、知识与经验的文字查找，支持日期／主题和问题式短句；显示实际匹配和范围，不能把未命中称为不存在。待更新知识可一键带入原范围重新分析，旧版本与个人说明继续保留。新结果明确接入经验，不静默覆盖旧知识。
7. **趋势图表**：7／30／90 天确定性记录覆盖折线图，选点下钻原始记录；未知日期和跨日资料单列，不折算假数。健康来源未接入时继续显示不可用。

## 一致性与体验

所有新模型请求由 ControlledAnalysis 执行，完整指令与派生上下文计量。过程绑定资料、任务与反馈版本，在途修改不允许发布旧结论。导航及搜索只供受信任页面使用，不能作为无限模型工具。持久建议若保存在任务中，删除、备份与恢复继续验证其实际依赖；旧包不覆盖本地用户决定。

普通阅读、屏幕重建、返回、重新打开和归档不启动付费请求。表单与任务身份保存，按钮显示请求范围与上限，失败保留进度。内容先呈现，技术说明按需展开；浅深色、小屏与大字体沿现有样式处理。

## 验收

- 用跨周合成记录完成：主题概况 → 查找旧经验 → 接入补充 → 行动实践 → 周期复盘 → 更新长期描述，并从每处判断回到依据。
- 本地查找涵盖长原文末尾和复盘答案，不把主题不匹配当作缺失；删除、修改和过期后无旧缓存误呈现。建议不直接写入主题或经验关系。
- 超过单次历史页的纠正都被扫描；同义被否定判断不得因改措辞或部分覆盖放行；用户批量选择仅作用于所见快照。
- 行动和画像 UI 使用现有发布条件，来源变化、模型拒绝、超预算、未采用与恢复中断均可解释；旋转不重复请求。
- 图表与现有指标同口径，日期选点对应精确来源，缺失健康数据不出现虚假折线。
- 建立可重复的合成质量案例，分别报告引用正确、语义评价与真实模型结果，不以总测试通过率宣称模型准确率。
- 执行相关测试、完整回归、lint、APK 构建及模拟器操作；发布同签名预览 APK，清理测试密钥并关闭模拟器。
