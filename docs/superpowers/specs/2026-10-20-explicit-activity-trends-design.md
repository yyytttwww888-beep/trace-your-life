# 工作与学习：明确输入和实际趋势

用户要求一次性补齐已知缺口，本设计落实工作／学习投入、亲自实践和成果的记录及趋势，不通过自由文本或笔记数量推断成长。与[主设计](2026-10-16-personal-knowledge-and-reflection-design.md)保持同一资料维护边界，接口定义见[看板](../../DASHBOARD.md#投入实践与成果)。

## 选择

采用固定结构化模板与普通记录答案。新建独立活动实体会重复实现修订、删除传播、取证、备份及阅读导出；从自然语言抽数字会把计划、时间点和时长混为一谈。现有模板已保留固定问题及历史版本，可以在保留自由随记的同时提供明确输入，且不需要扩展主库或完整备份格式。

每次填写一项实际活动，主要领域为工作或学习。分钟、亲自实践次数、具体成果、方法／条件均可选，零与未填不同；活动日期可未知或跨多天。表单仅验证单位和整数范围，不替用户判断是否成长。编辑保留原 ID、附图、额外主题和修订；被修改的模板含义必须重新有明确协议才能纳入数字，不能根据相似题目猜测兼容。

## 可重建视图

统计只取当前修订中的有限标量字段，不读取自由正文或成果全文。7／30 天逐日，90 天按现有自然周切分，各字段分别保留填写天数和缺口。未填为 null，明确零值可绘点；线条不穿越缺失时段。日期区间、未知时间、非法字段和不兼容模板各自有来源入口。不同记录之间不猜测行为是否重复，输入端说明一次活动只记一次。

成果时间线读取用户明确填写的成果字段，只作日期导航和原文呈现。不能把一段普通文字或成果条数变成成长量。比较区并列同长度前期及覆盖，不产生因果或能力评分。

所有页面与看板导出沿用来源／分析代数和跨日有效期；来源编辑、删除、归档、恢复使旧快照失效。看板 v2 增加独立活动 CSV／JSON 和成果字段定位，保持不复制原文的原边界；完整阅读包与加密备份已有模板、答案和修订，照原路径交付完整资料。

## 验收

使用合成资料检验：普通笔记出现“三小时”不产生时长；明确 0 与未填在图表和导出中不同；两项字段互不补零；跨日／未知不摊分；旧模板版本在新版本变更后仍正确；修订替换数值而非叠加；归档、删除和恢复遵循原快照边界；数据通过加密备份恢复后仍保留 0、缺失和旧修订；成果能下钻原文，不按数量评价成长。页面检验输入重建、保存、切换领域／窗口、图表来源和成果时间线，实际运行由统一验证记录说明。
