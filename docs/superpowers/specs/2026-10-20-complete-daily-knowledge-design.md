# 日常个人知识库：完整需求收口

用户要求一次性核清缺口、实现、评审和交付，不再按零散功能反复等待继续。范围以既有三份主设计和后续明确约定为准；餐食照片、通用历史导入、多用户与双向同步仍暂缓。

## 方案

采用现有主存和受控执行协议上的完整纵向流程，避免另建第二份个人资料库。单纯增加入口不能补齐自动积累和真实指标；无边界后台生成、全库上下文或直接改写正式画像会破坏现有证据约束，因此不采用。

1. **持续整理**：在既有后台队列、恢复栅栏及付费额度内加入自然周、自然月复盘和选定维度的月度长期画像候选。默认关闭；显式启用后按固定周期登记，暂停可续，失败不隐形重试。待查看页汇集草稿、失效知识和需处理状态。生成候选与用户采用仍分开。
2. **实际投入与实践**：以版本化结构化记录保存工作／学习领域、明确分钟、实践次数及成果文字，允许空缺。程序计算 7／30／90 天趋势并提供来源下钻与导出。未知不当零、笔记数量不当成长、成果文字不自动等于成果数量。
3. **个人概览**：用用户独立记录维护当前阶段、目标、关注点、观察信号和回看日期，汇集已有当前画像、经验、行动及待更新提示。阅读包增加概览、用户补充及变化导航，保留固定原文身份。
4. **定位与分类**：查询含义扩展通过独立受控调用生成导航词，不能生成个人事实；与主题别名、文字及完整分页目录共同选择有限的已有理解。模型仍只读取预算内背景及范围内分片原文。记录分类提供语义候选，确认后更新主题；已有主题可通过明确别名统一导航，不静默改写历史标签。
5. **可靠性**：针对已发现的覆盖误报、背景与事实混用、事件计数、时长误读、因果升级和不完整行动信号修正通用规则；固定原测试材料，验证生成、原文核对与发布门槛。新增功能同样覆盖删除、修订、恢复、并发和预算。不能以一次测试推导自然语言永远正确。

## 统一验收清单

| 原始目标 | 本轮验收 |
| --- | --- |
| 随记与专业复盘模板 | 回归离线保存、模板导入与旧版本绑定；新活动和概览记录复用修订及备份 |
| 自动沉淀 | 周／月草稿、长期候选、待查看入口，周期幂等、额度和恢复撤销授权 |
| 分类与串联 | 换说法、未分类原文、较老知识、主题别名、旧理解／行动／画像身份区分 |
| 工作学习趋势 | 真实输入、空缺与零、按日／周绘图、成果时间线、来源和导出 |
| 长期个人理解 | 阶段目标概览、跨期候选、历史意见和反例核对、明确采用、变化可查 |
| 分层知识库与其他模型阅读 | 分页目录、概览和用户补充、固定身份、链接有效；不要求外部模型一次读全库 |
| 维护正确 | 修改、删除、纠正和恢复传播；失效不冒充当前；原始文字及独立用户说明可靠保留 |
| 分析质量 | 固定合成案例、独立语义评审、生成至发布完整流程；失败及未知如实记录 |
| Android 使用 | 统一构建、升级保留数据、模拟器实际流程、密钥清理和关闭；真机验收单列 |

## 外部依赖与交付边界

华为连接尚未实现且准入未验证。真实接入依赖 AGC 项目、包名与签名配置、获批字段、华为账号授权、运动健康分享及真实设备数据。不能用模拟数据或空连接器替代实际接入；核验官方资料后记录具体条件和可以执行的配置步骤。

实体手机后台、厂商节电、实际换机恢复和长期个人使用效果，需要对应设备和资料验收。所有能在当前环境完成的代码、自动测试、真实模型合成验证、模拟器流程、文档和预览 APK 在同一轮交付。实现状态和实际检查逐项记入开发文档及路线图；不把未验证条件藏在“全部完成”中。
