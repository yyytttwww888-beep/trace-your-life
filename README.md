# Trace Life

面向个人的 Android AI 记录与知识管理应用。将日常随记和复盘组织成可追溯、可分析、可迁移的个人知识库，帮助理解近期变化、长期模式和下一步行动；计划扩展授权健康数据，餐食照片分析暂缓。

**当前阶段：前端首轮接入。** 已有离线记录、数据转移、DeepSeek 受控整理与核对、知识发布、周期综合、指标与看板、行动回看、纵向画像与维护、后台增量整理及看板偏好后端；本轮为这些后端接入首轮页面。健康数据和华为接入待验证，餐食照片暂缓。实现与验证见[开发文档](docs/DEVELOPMENT.md)与[开发路线](docs/ROADMAP.md)，真实模型与自动测试分别记录。仓库管理代码和设计，个人资料保存在应用数据区。

手机试用：[下载 Android 预览版 APK](https://github.com/yyytttwww888-beep/trace-your-life/releases/download/v0.1.0-preview.1/trace-life-0.1.0-preview.1.apk)（Android 8.0 及以上）。安装与验证范围见[预览版说明](docs/DEVELOPMENT.md#android-预览版)。

## 当前可用功能

- 新建、编辑随记和复盘；记录日期、日期区间或未知时间，支持补记及多个主题。
- 按日期与主题分页查阅，查看修订历史、归档／恢复和永久删除。
- 使用内置每日、每周、事件模板；导入文本或 Markdown，预览后保存个人模板，并保留版本与旧复盘绑定。
- 将图片作为受管附件保存；当前阶段尚不识别食物或生成 AI 分析。
- 界面基于系统控件，采用统一的小而美设计系统（`ui/Ui.kt`：深青主色、中性卡片、统一圆角与语义状态色，浅色／深色双模式）。
- 看板、核对与整理、知识库、行动实验、周期复盘材料、个人画像、备份与导出及设置（DeepSeek 密钥、后台增量整理）页面已接入对应后端接口；周期综合归并、周期原文核对发布与画像跨任务维护的流程页面仍未接入，图表渲染后置。

新增后端能力：可移植口令加密备份、带预览与版本检查的恢复、分层 Markdown／JSONL 阅读包，以及指定问题／范围的证据包。用法、格式与限制见[数据转移接口](docs/DATA_TRANSFER.md)。完整备份保留修订、旧模板绑定、附件与删除记录；阅读包明确不用于恢复。

受控分析后端支持按范围分页定位、按字段分片取证、完整请求预算、每次调用的引用校验、失败恢复和幂等重试。结果保存为待核对提案，来源变化会阻止旧任务继续执行；任务与证据台账同时纳入加密备份。用法见[受控分析接口](docs/CONTROLLED_ANALYSIS.md)；DeepSeek 密钥配置、自动分批及显式真实测试见[接入说明](docs/DEEPSEEK.md)。

陈述核对重新取得原文及显式选定的上下文，分别保存模型意见、用户确认／纠正／否定及证据有效性。用户独立文字在来源删除后仍保留，旧备份不能覆盖目标库已有反馈；用法与限制见[核对与反馈接口](docs/CLAIM_REVIEW.md)。

通过最新核对的陈述可条件发布为观察、知识条目或经用户确认的洞察，保留修订、证据与失效状态，并进入分层阅读包。记录指标由程序计算每日记录数和日期覆盖，支持按原始记录下钻；不据此计算成长或健康评分。用法见[知识与指标接口](docs/KNOWLEDGE.md)。

自动整理可在共享请求上限内继续提取、核对与发布，保留失败和待确认状态。周期材料按原模板意图组织期望、实际、因素、经验、行动与回看，支持原文分片查阅及 Markdown／JSON／CSV 包导出；这是已有材料视图，尚未生成新的周期判断。接口和限制见[自动整理与周期复盘材料](docs/PERIOD_REFLECTION.md)。

新增综合接口对多条原文作有界对照，提出待确认解释，并在核对时重读全部批内上下文；大范围分批完成与跨批统一综合分别报告。用户可明确选择行动实验，保存触发、做法、预期信号、回看日期，之后记录执行、观察、调整或停止；修订及回看纳入完整备份。用法见[综合与行动接口](docs/SYNTHESIS_ACTIONS.md)。

新增分层归并将多个综合批次按预算逐层整理为周期草稿，保留依赖、空结果和覆盖缺口，支持原文下钻与反馈失效传播。通过[分层周期草稿](docs/PERIOD_REDUCTION.md)生成后，可逐批扫描完整来源链、重新核对全部相关原文，并在用户确认后发布为正式洞察。扫描、最终意见和采纳决定分别保存；预算不足或上下文缺口会阻止发布，父反馈变化与删除向知识、行动来源和导出传播。用法见[周期原文核对与发布](docs/PERIOD_REVIEW.md)。

新增[受控指标分析](docs/METRIC_ANALYSIS.md)，由程序计算完整范围的记录覆盖，AI 解释后重新计算并核对；用户确认后可发布洞察，凭据随备份和范围导出保存。模型只读取统计结果及口径，原始来源清单保存在本地。

新增[看板数据接口](docs/DASHBOARD.md)，提供 7／30／90 天记录覆盖、前期比较、实际贡献来源下钻、匹配的已发布说明及全局行动回看，支持 Markdown／JSON／CSV 包导出。健康卡片如实显示来源不可用；资料、反馈、行动变化或跨日到期时拒绝旧快照。[看板偏好](docs/DASHBOARD_PREFERENCES.md)已支持保存、重启读取及备份恢复，图表与设置页面后置。

新增[画像采用与维护接口](docs/PERSONAL_PROFILE.md)，将已有观察／洞察按八个维度及长期、情境、近期层次组织，保存候选、采用、不采用、被替代与独立用户文字。固定知识修订和证据仍由知识库维护，来源失效后退出当前画像；支持历史分页、证据下钻、完整备份和分层阅读导出。该维护接口组织已有知识；新的描述通过[受控画像候选生成](docs/PROFILE_CANDIDATES.md)从限定范围原文分批提出，重读整批原文核对，由用户确认后明确保存为候选，采用仍是独立操作。普通候选入口处理近期状态与情境模式；[纵向画像](docs/LONGITUDINAL_PROFILE.md)按多个周期分批生成长期候选，并要求完整范围维护核对。多批尚未整合及反例搜索缺口分别报告。

新增[跨任务画像维护](docs/PROFILE_MAINTENANCE.md)，对新候选逐项检查已有画像及历史纠正、否定、撤回，再分批扫描当前范围全部可读原文。最终核对重读相关原文和生成批次，保留反例与缺口；用户明确选择后在原画像 ID 上收窄或替换，保留历史、独立文字并回到候选。比较关系不等于新的原始证据，模型建议不会自动采用。

新增[行动周期分析](docs/ACTION_PERIOD_REFLECTION.md)，将原计划、执行回看与日常记录作为不同证据对照；可逐层归并多批成果，扫描全部来源并重读全部相关原文，经用户确认和模型支持后发布。相关资料超过最终核对预算时保留草稿、阻止发布。已发布行动洞察可进入[知识阅读包](docs/DATA_TRANSFER.md)，通过分页索引定位固定计划与回看修订；行动修改、删除、反馈和恢复继续检查完整依赖。

新增[后台增量整理](docs/BACKGROUND_ANALYSIS.md)，默认关闭，启用后处理之后新增或修订的记录，支持暂停、取消、持久请求额度与显式失败恢复；仅执行提取与核对。备份恢复会撤销旧自动授权。新增[画像变化摘要](docs/LONGITUDINAL_PROFILE.md)按修订列出知识引用、采用和用户补充变化，不计算个人成长分数。

构建、安装及验证命令见[开发文档](docs/DEVELOPMENT.md)。当前仍用合成资料验证；文件选择与恢复确认已接入备份页面，真机验收待完成。

## 产品范围

- **低负担记录**：随手写、不完整记录、事后补记；可选有深度的日／周／事件复盘，支持导入个人模板。
- **AI 整理与分析**：提取观察、知识和有依据的洞察，形成行动并在后续复盘中回看。
- **关键趋势看板**：聚焦睡眠、运动、饮食、工作学习及行动的关键变化，数值可追溯，缺失资料明确显示。
- **长期个人画像**：区分自述、近期状态、情境模式与长期倾向，保留支持、反例和用户修正。
- **丰富输入**：计划接入华为运动健康，资格、目标字段和真实设备授权仍需验证；餐食拍照分析按用户要求暂缓。
- **资料自主保存**：手机本地主存，支持完整恢复备份、分层知识包、指定范围证据包及指标／报告导出。

首版面向个人使用，不包括多用户服务、通用历史资料导入或多设备双向同步。个人模板导入和完整备份恢复属于首版范围。

## 核心架构

结构化资料与受管附件共同构成权威资料；Markdown、分层索引和看板是可重建视图，已经生成的 AI 分析保留内容、证据和版本。模型读取必须经过程序执行的范围、快照、索引路由与预算约束。

```mermaid
flowchart TD
    Inputs[随记 / 复盘 / 照片 / 授权设备数据] --> Store[手机本地资料与附件]
    Store --> Index[分层索引与证据定位]
    Index --> Retrieval[范围与快照约束下按需取证]
    Retrieval --> AI[AI 整理与分析提案]
    AI --> Validate[证据 / 覆盖 / 版本校验]
    Validate --> Store
    Store --> Metrics[确定性指标计算]
    Metrics --> Views[看板 / 周期复盘 / 当前画像]
    Store --> Views
    Store --> Export[完整备份 / 知识包 / 任务证据包]
```

资料保存在本地；用户已选择 DeepSeek 云端模型，调用时会发送本次任务选中的原文片段、已登记的派生草稿或程序指标；画像维护还会按预算读取历史描述和相关用户反馈作为控制背景，行动周期分析读取已登记的计划与回看。凭据独立加密保存，不进入备份或 APK；供应商资料处理依据与限制见[接入调研](docs/research/2026-10-17-deepseek-integration.md)。
